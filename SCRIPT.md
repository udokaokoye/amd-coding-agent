## HOOK (0-5s)
*[Screen recording: Task Manager open, NPU at 0%]*

"Your laptop has a dedicated AI chip and you're not using it."

## SETUP (5-15s)
*[Still on Task Manager, point at NPU]*

"See this? NPU. Neural Processing Unit. 50 trillion operations per second just sitting there doing nothing while you're paying OpenAI every month to run your AI stuff in the cloud."

*[Switch to terminal, run the coding agent]*

"So I built this — a coding assistant that runs entirely on my laptop. No API keys. No cloud. No data leaving my machine."

*[Show the agent analyzing code]*

"I point it at any codebase, and it reads my files, understands the structure, answers questions about my code."

## THE PAYOFF (25-40s)
*[Split screen: terminal on left, Task Manager on right showing NPU spike]*

"Watch the NPU."

*[Type a question, model starts generating]*

"See that spike? That's the AI chip doing actual work. Not the GPU. Not the CPU. The dedicated AI engine."

*[Response streams in]*

"And it's fast. Like, actually usable fast."

## THE CLOSE (40-55s)
*[Back to face or full screen terminal]*

"Here's the thing nobody's talking about — these AI chips in new laptops aren't just for Copilot and whatever Microsoft wants to do. You can build your own stuff on them."

"Local AI agents. Private coding assistants. Automation that doesn't phone home."

"The tools are here. The hardware is here. We just gotta build on it."

## CTA (55-60s)
